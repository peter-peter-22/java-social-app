# The Typescript client is deprecated

The TS client is planned to be generated from openAPI instead.
It should use pnpm.
The current TS codes are not tested and updated to avoid work that will be overwritten.
The current TS client served its goal by proving that the web API is accessible from here, 
further updates won't be necessary until the final web client is built.
The java e2e tests are checking the same endpoints that TS would see.
