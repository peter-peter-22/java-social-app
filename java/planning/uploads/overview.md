# Upload service overview

## Summary

A group of services for handling media uploads and transformations.
Similar to Cloudinary.

## Definitions

- Upload: A file uploaded to the service. It has a unique upload key.
- Transformation: A process that takes an upload and outputs a variant.
- Variant: The output of a transformation. Can consist of a single file or multiple files.
- Named transformation: Transformation parameters registered with a unique name.
- Eager transformation: A transformation that is applied after upload. The upload is considered ready only after this finish.
- Incoming transformation: A transformation that overwrites the original upload when completed. It is applied before the eager transformation.
- Async transformation: The eager+incoming transformations can be blocking or async (queued).
- Signature: A stateless HMAC-SHA256-signed credential generated by the main application for one private upload version. It is presented as the `v`, `e`, `s`, and `k` query parameters of a read URL and grants the original and every variant of that version. Also called a download token.
- Upload permission: A database record that registers the upload key, parameters, constraints, transformations, and visibility of an upload. It permits the client to upload one file, has an expiry, and has a limited use budget.
- Upload request: A file upload with an upload permission from the client.
- Read: The uploads and their variants can be read from the client.
- On-demand transformation: A transformation that is executed during read and then cached. 
- Authorization: The access limitation of an upload. Some uploads are private. They require a signature to be read.
- Completion webhook: A URL that is called after the upload and it's transformations are completed if provided.
- Main application: The application that communicates with the upload service, has the admin key, can define transformations, can create signatures.
- Asset: Objects registered into the database with a directory-like structure. All assets have an entrypoint, this highlights one of their objects. Some assets have a single object while some others have multiple (these are also called directory assets).
