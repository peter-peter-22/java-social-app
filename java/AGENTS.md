# Java social media application

This is a learning project about java spring boot, scalable architecture, large applications and social media related algorithms (e.g., ranking, fanout, uploads, notifications).

# Warning
The project contains the remains of older prototypes. 
The real code is in the upload-registry and upload-api modules of
the uploads-v2 folder.
Other modules are considered irrelevant and probably won't compile.

The code is currently disorganized, the refactoring is postponed until the main parts are functional.
